【实测过程（2026-11-04，全部为未登录公开 GET）】
1. 客户端 39 chunk 静态扫描（2026-11-03 mine-all.mjs 聚合）：0 个业务接口路径字面量。
2. _next/data 探测：GET https://kaipai.com/_next/data/test/test.json
   → 301 → www → 200 但 Content-Type: text/html，1,416 字节兜底页
   （证据 next-data-probe-404fallback.html）。
   结论：App Router 站点不存在 Pages Router 的 /_next/data/<buildId>/<route>.json 数据路由，
   交接文档第 3.2/5 章设想的「改走 _next/data」路径对本站不适用（技术性关闭，非未尝试）。
3. RSC 通道：GET https://www.kaipai.com/ 带 RSC:1 → 200（证据 rsc-payload-home.txt）。
   交付的是 flight 渲染载荷（页面内容），不是接口契约，无路径/方法/字段可提取。
4. 后端 API host 线索（新增发现）：<link rel="preconnect" href="https://webapi-action.meitu.com"/>
   —— 开拍（美图系）运行时业务 API 基址。其端点需登录 workbench 后由前端调用，
   公开资产中提取不到具体 path/字段（登录态属红线，未触碰）。
