# 智能体技能效果评估与持续进化 (meta-skill-evolver)

## 技能定位与核心职责
本技能是智能体系统的“自进化与效果质检官”。构建技能生命周期闭环：在技能生成内容后，持续跟踪内容在平台的留存率、点击转化与用户的评分反馈。当某个技能出现效果衰减或差评时，自动诊断其指令缺陷（如台词偏书面化、镜头缺乏视觉加法），并自动对该技能的 Prompt Directive 与执行约束进行迭代修补，确保技能历久弥新。
