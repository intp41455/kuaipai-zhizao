# 投流与人群反哺 (local-campaign-analytics)

## 技能定位与核心职责
赋能岗位：**同城投流优化师 / 商业数据分析师 / 运营主管**
本技能是本地生活实现从“盲目投流烧钱”到“科学种收循环”的数据舵手。严格遵循“先种后收、人群蓄水、漏斗归因、反哺创作”的闭环方法论。通过监控巨量云图 5A 人群资产（尤其是 A1 了解人群与 A2 吸引人群），设置安全阈值闸门；通过曝光-点击-下单-核销漏斗分析，评定素材红黑榜，输出切实指导下周编导摄制的反哺工单。

## 一、“先种后收”与 5A 人群资产安全阀机制

实体同城流量算法对本地商户有严格的“人群资产池”要求：

```
[A1: 了解人群 (同城潜在曝光)] ───► 必须蓄水 ≥ 30,000 人（安全阀门槛）
          │
          ▼ 
[A2: 吸引人群 (完播/停留/互动)] ───► 提升种草深度，沉淀同城忠实粉丝
          │
          ▼ 
[A3: 询问人群 (搜索/查看门店/加购)] ─► 关键转化蓄水池
          │
          ▼ 
[A4: 购买人群 (线上购买团购券)] ──► 转化拔草单核心承接
          │
          ▼ 
[A5: 忠诚人群 (到店核销/二次复购)] ─► 私域沉淀与老客复购
```

### 🚨 投流安全阀红线 (Kill-Switch Policy)
- **A1 潜客蓄水不足（< 30,000 人）**：
  - **亮黄灯！严格阻断直接投放高客单价拔草单！**
  - **应对动作**：预算 100% 倾斜向“短视频自然加热”与“同城泛曝光”，主投前 3 秒高完播率的内容视频，快速放大 A1 人群池。
- **A1 潜客充足（$\ge$ 30,000 人）**：
  - **亮绿灯！允许启动同城定向团购投放！**
  - **应对动作**：采用“小额多组冷启动”，用 100 元定向投流撬动爆款单品团购放量，冲击 1:300 综合投入产出比。

## 二、展点 / 点购 / 核销全链路漏斗归因

投流分析必须细分每一跳的流失原因与责任归属：

| 漏斗阶段 | 关键考核指标 | 达标基准 | 异常排查与归因诊断 | 责任归属 |
| :--- | :--- | :--- | :--- | :--- |
| **第一跳：曝光 ➔ 播放** | **前 3 秒播放率** | **$\ge$ 82%** | 若 < 70%，说明前 3 秒钩子平铺直叙、画面缺乏视觉冲击。 | 编导（重写Hook） |
| **第二跳：播放 ➔ 点击** | **千川点击率 (CTR)** | **$\ge$ 4.5%** | 若 < 3.0%，说明中段卖点证明不够、视频无明确利益引导。 | 剪辑/编导（补微距与字幕） |
| **第三跳：点击 ➔ 下单** | **落地转化率 (CVR)** | **$\ge$ 15%** | 若 < 8%，说明团购货盘价格缺乏竞争力，或套餐内容不诱人。 | 运营/商务（优化组品） |
| **第四跳：下单 ➔ 到店** | **真实核销率** | **$\ge$ 55%** | 若 < 40%，说明预约流程繁琐，或同城地理定位不清晰。 | 门店前台/店长（优化核销） |

## 三、素材红黑榜评定与创作反哺指令

### 1. 红榜素材（优质爆款，予以追加预算）
- 特征：3 秒完播率 > 85%、千川 CTR > 5%、投流 ROI > 保本线 1.5 倍；
- 动作：将该素材作为“母版”，提取其核心运镜与音频切片，裂变为 5 条不同前 3 秒钩子的矩阵切片。

### 2. 黑榜素材（劣质衰退，立刻停投下架）
- 特征：3 秒完播率 < 65%、千川 CTR < 2.5%、消耗预算达 50 元仍无有效订单；
- 动作：立刻关停计划，提取其失败节点（如：第 4 秒转折过长、画面偏暗、声音混响严重），归档入《避坑案例库》。
